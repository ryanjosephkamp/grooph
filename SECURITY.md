# Security

## Reporting a problem

Report a security problem privately, with GitHub's **Report a vulnerability** button on the repository's **Security** tab. Do not open a public issue for it.

If the button is not there, open a public issue that asks for a private way to send a report, and leave out the details of the problem. A private channel will be given in reply.

Say what you found, how to reproduce it, and what it lets someone do.

## What is covered

The app at https://ryanjosephkamp.github.io/grooph/, the `grooph` package on npm, and this repository. grooph has no server and no accounts. What it guards against is described in [docs/security.md](docs/security.md): links, size caps, escaping, the offline page, and embeds.
