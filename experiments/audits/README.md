# Audits

A claim about what grooph does is read by a second tool before it is published. This folder holds the findings of each audit: one folder per audit, with the auditor's report and the reconciliation of each round.

| Audit | Subject | Rounds | Result |
|---|---|---|---|
| [`0001-claims-as-of-0-3-0`](0001-claims-as-of-0-3-0/README.md) | Every claim grooph published as of 0.3.0: the README, the front page, the site's pages, the technical report, and the blog draft (52 claims) | 3 | 21, 16, and 19 findings; none disputed; the corrections are in the product's pages and code |

The auditor's prompts, its probe scripts, and their printed output are not kept in the repository. The reports say what each probe showed.
