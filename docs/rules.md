# Rule reference

Every rule grooph checks, by its stable code: what it says, what `grooph validate` prints when it fires, a document that fires it, and one that does not. `E_…` is an error; `W_…` is a warning, which is shown and does not stop anything. The advice about loops and stops is a warning whatever its code begins with, and is given when asked for (`--loops`).

_Generated by `scripts/rule-reference.mjs` from the rule tables and `fixtures/`. Do not edit it; CI fails when it is stale._

## Graph documents

Checked by `grooph validate <file>`; `--complete` adds five rules for a finished document: `E_UNFILLED_SLOT`, `E_NO_GOAL`, and `E_IS_TEMPLATE`, which any finished diagram passes, and `E_NO_TARGET` and `E_PERSON_STEP_NOT_COMPILED`, which only a package for a harness needs (experimental) and a plan keeps. A filled-in diagram is worth checking with `--complete`, because it is what reports a `{{slot}}` left unfilled. `--for-export` is the flag's old name, and still works. `--loops` gives the advice about loops and stops: six rules given as warnings, under their own codes, and never as errors. The rules are defined in [graph-ir.md](graph-ir.md) §3.
