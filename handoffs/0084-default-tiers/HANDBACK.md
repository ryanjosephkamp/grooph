## What the new default makes one model

For all twenty templates, each critic against its nearest writers, which are the pairs `W_HOMOGENEOUS_CRITICS` looks at.

| | Templates | Under the default |
|---|---|---|
| **A critic and the builder it checks become one model** | `contradiction-seeker` (critic `strong` over builder `fast`) | both `sonnet`; they were `opus` over `sonnet` |
| **They were one tier already**, and the validator says so | `review-gate`, `spec-then-loop`, and four of `specialist-critic-bank`'s five critics (all `strong` over a `strong` builder) | both `sonnet`; they were both `opus` |
| **They stay apart**: a `frontier` critic over a `strong` or `fast` writer | `debate-then-build`, `dual-bar`, `fresh-grind-rare-judge`, `gauntlet-decomposed` (both critics), `heterogeneous-critic`, `metric-sandwich`, `red-team-loop`, `taste-polish`, `tournament-then-judge` (its judge over all three candidates), `specialist-critic-bank`'s triage | `opus` over `sonnet`; they were `fable` over `opus` or `sonnet` |
| **No critic over a writer** | `grind-loop`, `human-gated-irreversible`, `merge-queue`, `ownership-not-swarm`, `patrol-pulse`, `ralph-loop`, `retrospective-rewrite` | nothing to collapse |

So one template of twenty loses the difference between its critic and its builder: **`contradiction-seeker`**. To keep them apart: `--models strong=opus`, or a pin on the critic. No template's own tiers were changed.

**The export's note, checked for each.** Every whole template was exported with nothing named (18; `human-gated-irreversible` and `merge-queue` are fragments and do not export alone). The note is about tiers, not pairs, so it is printed for the six with agents on both `strong` and `fast`: `contradiction-seeker`, `debate-then-build`, `ownership-not-swarm`, `patrol-pulse`, `retrospective-rewrite`, `tournament-then-judge`. It reads:

```text
note: strong and fast are both sonnet in this package, by the target's own map, and this graph has agents on each. A critic and the builder it checks may share a model; the validator's check for that reads tiers and does not see it. To keep them apart, name the tiers: --models, or GROOPH_MODELS.
```

In five of those six the agents on the two tiers do not judge one another; the note says "may". The other twelve print no note.

## Decisions made

1. **The export's note is printed for the target's own map too.** It was printed only when the one exporting had named a tier, so the collapse the new default brings would have been silent for everyone who names nothing, which is most people. The wording differs by a few words: "by the target's own map", "may share" where the named case says "may now share", and how to keep them apart.
2. **The help reads the map from the profile**, not from a second copy of the three names, so it cannot drift.
3. **The help's example stays** (`--models frontier=opus,strong=sonnet,fast=haiku`): it still shows all three tiers named and differs from the default in one.
4. **The list is by pairs the validator looks at** (a critic and its nearest writers), computed from the twenty pattern documents, not read off by eye.
5. **`docs/releases.md` gets a "Not yet released" heading** above 0.3.0. The brief forbids a version number, and the sentence has to stand somewhere until there is one.

## Deviations

- **`packages/cli/src/commands/export.ts` changed what the command prints.** The brief says the export "already prints a line when two used tiers become one model" and asks to check that it does. It did only when a tier had been named. Making it do so for the default is the brief's purpose, but it is a change to the command and not a place the default is repeated.
- **`handoffs/0079-tier-map/HANDBACK.md` is not on `main`**, and not at that path on `origin/slice/0079-tier-map` either. I read the code that slice left (`export.ts`, `context.ts`, `mapping.ts`) instead.

## Risks and leftovers

- **Three places still name `fable`, none of them mine to change here.**
  - `.claude/agents/slice-0007-sandwich--critic.md` (`model: fable`) and `.grooph/slice-0007-sandwich/MAPPING.md`: a package placed in this repository for slice 0007. Its critic is an agent a session here can dispatch, and it would run on Fable. One line, or a fresh export of that graph, fixes it.
  - `scripts/lib/compare-run.mjs`: the evidence lane's, forbidden here.
- **The app's Export panel says nothing of tiers.** It shows no map, so there was nothing to change, and it prints no note: a person who exports `contradiction-seeker` from the app is not told its critic and builder are now one model. The package's `MAPPING.md` does carry the map.
- **The note is about tiers, not pairs.** It is printed for five templates whose `strong` and `fast` agents do not judge one another. A note that looked at the pairs would be quieter and exact; that is a change to the compiler's output, not this slice.
- **Proving records and write-ups are history** and still say what each run used (`claude-fable-5-1` among them). None states the default as a fact about today, so none was changed.
- **The second study's own map** is whatever `scripts/lib/compare-run.mjs` names; this slice makes the default equal to what the brief says that is, and did not read the evidence lane's file to confirm.
