# Handoff 0084 · The default tiers, without Fable

**Stage:** 24 · **Lane:** Opus 5.5 · **Effort:** high · **Browser tests on port:** 4361 · **Branch:** `slice/0084-default-tiers` · **Drafted:** 2026-10-04 · **Confirmed by owner:** 2026-10-04, on the review desk ("Change the default to Opus for everyone") and in the chat ("Default tiers: let's do the same as the study")

## Objective

The Claude Code target's own tier map says `frontier` is Fable, `strong` is Opus and `fast` is Sonnet. The owner has decided that grooph's default, for everyone, is the map study two runs with: **`frontier` = `opus`, `strong` = `sonnet`, `fast` = `sonnet`.** A person who wants another map names it with `grooph export --models` or `GROOPH_MODELS`, as today.

Make that the default everywhere the default is written, and say honestly what it changes.

## What to make

1. `packages/core/targets/claude-code.profile.json`: the three names.
2. Every place that repeats them: `docs/targets/claude-code.md`, `docs/graph-ir.md` §4, the golden packages under `fixtures/golden/` (regenerated by export, never by hand), the app's Export panel if it shows the map, the CLI's help and `docs/cli.md` (regenerated), the pattern write-ups only where they state the default as a fact about today.
3. **Say what collapses.** With `strong` and `fast` the same model, a critic on `strong` over a builder on `fast` is the same model judging its own kind. List, for all twenty templates, which critic and builder pairs become one model under the new default and which stay apart (a `frontier` critic over a `strong` builder stays apart). Put the list in `docs/targets/claude-code.md` and in the handback. The export already prints a line when two used tiers become one model: check that it does for each such template.
4. One sentence in `docs/releases.md` for the next release: the default changed, and how to get the old map back.

## Success criteria

- `grooph export` of any template with no `--models` and no `GROOPH_MODELS` writes no file that names `fable`.
- The golden packages differ from `main`'s only in model names and the mapping's lines; say so with the diff's summary.
- Every CI job passes, and `node scripts/perf-budget.mjs --check` with no line raised.
