One thing you should know

The first version of the new events command had a dangerous flaw, and an independent reviewer caught it before I pushed anything. If a lane had pointed it at its own work branch, it would have replaced that branch's contents with only the event files. In Splashery that could have wiped a lane's branch. The command now refuses any branch that holds anything other than event files, and the branch a lane has checked out, and sends nothing. Five tests cover it, including that refusal. The flawed version never left this Mac.

The reviewer was a subagent with no part in writing the code. It also found four smaller faults, all fixed. This is the second time an independent read has caught something my own tests missed, so I will keep doing it for anything that writes to a repository.
