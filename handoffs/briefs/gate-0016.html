What I changed (0.2.4)

  • Only this session's files go. At a turn's end the hook now sends a file only if it is that session's own, was written since it began, or is already on the branch. Old leftovers stay put.
  • No paths leave the machine. A folder is sent as its name, not its full path, and a subagent transcript's path is not sent at all.
  • Small repairs. Half-written lines wait for the next push. Reading the local folder and the branch together no longer counts anything twice.

  2. May the lanes publish their events on the other project's public repository?

    An events branch would hold, and only hold:

    • session and subagent ids;
    • model names and agent types, including the names of any custom agents;
    • tool names. A tool from a connected service carries the service's name, for example mcp__github__…;
    • when each session, turn, subagent and tool call started and stopped;
    • the working folder's name.

    It never holds a prompt, a file name, a command, what a tool read or wrote, or a reply. Treat anything pushed as public for good.

    I recommendyes. It shows when the lanes work and with which tools, which is less than their commits and pull requests already show.
