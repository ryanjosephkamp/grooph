T1–T6

Themes

The same picture six times: the review loop from the repository's fixtures, exactly as grooph image writes it. A theme is a set of values for the picture's color variables, plus a few style rules for lettering, line weight and corners. The graph document and the picture's markup are identical in all six, so a theme costs an agent nothing. It never sees one.

In all six, a gate is the card with the heavy outline and the words Human gate, a loop edge is dashed and labeled fail, and a stop has its own corner shape. Color repeats what shape and words already say.

Where a theme has a light and a dark form, this page's theme picks it. T4 has one form and stays dark.

Three costs to know. Every theme after T1 changes some lettering, so the drawing code would have to measure text in that face, or use one no wider than today's, as these five do. T6 needs one small filter placed beside the picture for the wobble. Square and pill corners come from a style rule that older browsers ignore, and there the corners stay as they are today.

      V1

      Three dimensions, and time

      The same map as a scene. Each lane is a sheet, each session a slab on its sheet, each handoff a tube in its carrier's color with its number. Flat lays the sheets out as rows seen from above. 3D stacks them. The slider lights the handoffs one at a time in the order the map lists them. The map records no times, so that is a reading order and says nothing about when a handoff happens.

      Depth gives each lane its own sheet, so a handoff that crosses lanes looks different from one that stays inside a lane, and the slider replays a long map one handoff at a time.

      Text is harder to read at an angle and from a distance, and the scene asks for a finger or a pointer before it makes sense.

      It must stay a view and never become the document, so nothing arranged in this scene would be written back into the file.

      It would load only when someone asks for it, so the app's speed budget is untouched.
