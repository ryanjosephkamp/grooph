## Decisions made

- **The vocabulary is generated from `OP_ARGS`, not typed by hand.** `OP_VOCABULARY` is a `Record<OpName, string>` (compile error if an op is added without a line) and the test checks every argument name appears on its line, so the brief cannot drift from what `grooph apply` accepts. A fenced text list rather than a table: 26 rows with `|` characters inside arguments (`-1 | 1`, `loop:<id>`) would need escaping, and a lead pastes from it.
- **Two example ops, `addNode` with `set` and `connect`,** because those are the two the retro invented wrongly (`addNode` with a `node` object, `addEdge`); the sentence before the list says so in one line.
- **The §5 diff bullet is conditional** on an edge's evidence naming a diff, so graphs whose critics read the repository do not carry it. `git add -N` is mentioned as the alternative since the runner now admits it.
- **The §8 copy rule is a lead instruction only, not a `KICKOFF.md` line** (the handoff left this open). The kickoff is the trigger and already defers to `LEAD.md` §"Progress and notes"; the "run commands bare" line earned its kickoff place because it is a permission matter for every command, and this rule fires once per round.
- **The check's item 15 is a finding either way,** kept or missing, on every round a critic ran that it ran again after (which includes a gate's reject re-dispatching the builder — a shade wider than the brief's "after a critic's `fail`", and said in the comment). It matches `-round-<n>`, `-round<n>` and `-r<n>` as the existing same-report rule does, so the bank lead's own `TRIAGE-round0.md` counts. Never a problem: the kept records predate the rule (decision 0009).
- **Dispatches per round counts agent members that are not the lead node, plus check members;** gates, merges and stops are named as "not a dispatch" so the lead sees why the number is smaller than the member list. The number of full rounds the budget covers is stated (floor and remainder), which is the arithmetic the bank's lead got wrong. An enclosed loop (members a strict subset, the `estimateShape` rule) is named as adding its own rounds on top. No change to `Shape` so `grooph shape --json` stays as documented.
- **The mid-run-node sentence was rewritten,** not just the capability rule, because its stated reason ("agent files are read when the session starts") is what the documentation contradicts; the brief now offers writing the node's own file first, with the general-purpose inline dispatch as the fallback. See Deviations.
- **`MAPPING.md`'s hand-edit section is three paragraphs,** tools in its own, rather than folding `tools:` into the model/effort YAML example: the table is the useful part, and the durable-place sentence differs.
