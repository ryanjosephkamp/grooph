## Deviations

- **One of the two runs happened.** Criteria 2 and 4-for-the-judge are unmet, and 1, 5 and 6 are met only for the bank.
- **A runner defect, reported not fixed** (`scripts/**` forbidden): `gate()` in `scripts/lib/prove-ledger.mjs` refuses a `--retry` kickoff when any earlier kickoff for that template carries `retry`, and the runner's own header tells you to re-prove *with* `--retry`. So a re-proof that fails for a reason outside the package — exactly what the retry exists for — consumes the retry. A fix that keeps the rule's intent: count an earlier retry only when it has `status: "ok"` (or a `run_id`), so an invocation that never reached a lead does not use it up; or give the ledger entry a `kind`/flag that distinguishes a re-proof from a retry. Either is a small change with a runner test, in a slice that may touch `scripts/**`.
- **The check reads parallel dispatches as estimated timestamps** (a finding, never a problem, and not fixed here). `prove-check.mjs:596-600` flattens `[started, ended]` in file order and flags any decrease as "estimated, not read from the clock". This lead repeated `started` on each of the four critics' result notes — all `03:30:27`, while the note before them already ended at `03:31:44` — so three legitimate lines look backwards. The first run omitted `started` on those notes and scored 0 out of order: same fan-out, opposite verdict. Worth teaching the heuristic about concurrent members, or comparing only `ended` against `ended`.
- **The $9.00 ceiling was not needed.** The raise was motivated by the first run's halt at $6.00; this run finished a full pass and reached the gate for $3.10. The bank's own earlier proposal (a `usd` stop on the loop) is no longer motivated by its record; both of its template asks are now closed.
